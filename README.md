以已确认的七叶角色为中心，连接蒙顶山茶文化、名山城市空间与日常文创的互动网页。

## 2026 年 11 月深化内容

保留七叶原图、主配色和五段旅程，加入逐章的七叶手记、故事与茶物之间的关联、名山五个城市停留点，以及包含 17 张设计图的茶物展馆。

展馆支持四个主题筛选、完整展板、180% 细节查看、前后件切换、故事回链和本机收藏茶篓。茶路卡会带上心境、城市停留与收藏茶物。用户文字草稿会在切换章节时保留。

## 如何替换、添加作品

1. 将图片放入 `assets/collection/`，建议使用短英文文件名。
2. 在 `content.js` 的 `products` 数组中修改相应对象。
3. `title` 是网站显示名称，以画面内容整理，不使用原始素材文件名。
4. `image` 指向完整展板，`thumb` 指向列表预览。没有小图时两者可填同一路径。
5. `category` 选 `mountain`、`tea`、`road`、`gift` 之一；`chapter` 为 0–4，分别对应种下、采制、出山、入城、分享。
6. `id` 必须唯一。章节与城市节点的 `productId` 通过此值关联作品。
7. 新增作品会自动进入展馆，筛选计数、收藏和设计档案无需另写代码。
8. 更新后重新发布。若使用 GitHub，在网站仓库 main 分支更新相同文件，Pages 会自动部署。

所有预览和展板保持原图比例，没有裁切，也不覆盖原始设计文件。新照片可以逐件替换，不影响其他作品。

## 文化叙事边界

- 吴理真七株茶树故事标为地方传说与传统记忆。
- 三种手法互动不代表完整制茶流程；不同茶类不能套用同一工艺。
- 古道图形是文化联系示意，不是导航。
- 甘露坊、名山河与茶马古城的叙述附公开资料来源。两个旧址节点依据用户提供的参赛命题资料，以更新想象呈现，不声称改造已经建成。
- 文创均展示为作者提供的设计效果图。材质、结构、温感效果、耐热等性能及尺寸尚需打样验证；未宣称已量产、已认证或已经销售。
- 茶园资料图来源见网站「故事的来处」，权利归原权利人，商业使用前应取得许可或替换自有照片。

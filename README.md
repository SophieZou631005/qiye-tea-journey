# 七叶 QIYE · 七株茶，万里路

蒙顶山茶文化互动数字文创网页。五章互动：种下、采制、出山、入城、分享。

这是 GitHub Pages 发布版本：HTML、CSS、JavaScript 与 assets/ 直接放在仓库根目录，无需构建、服务器或安装依赖。
字体、图片与二维码脚本均为本地资源。二维码和分享链接随当前网页地址生成。

内容维护：content.js；视觉：styles.css；交互：app.js。后续照片放入 assets/ 并更新 content.js 的 products。

角色使用已确认的七叶原图。茶园摄影引用与字体许可见网页资料来源及 assets/ 中的说明。商品展示为尚未打样的概念。
